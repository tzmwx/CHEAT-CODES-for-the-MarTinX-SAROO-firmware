# CHEAT-CODES-for-the-MarTinX-SAROO-firmware
MarTinX SAROO的固件20260514支持金手指.scht文件

下载后解压缩到SD卡，注意readme文件

SAROO/CHEAT中的F文件夹和ID文件夹

文件夹：SAROO/CHEAT/F/gamename.scht

gamename必须与SAROO/ISO/GAMENAME文件夹名称相同

文件夹：SAROO/CHEAT/ID/game-id.scht

系统根据game-id自动匹配，不需要特意设定SAROO/ISO/GAMENAME文件夹名称
